# Contributing to Ciger ⚡

Thank you for your interest in contributing to **Ciger**! We welcome bug fixes, hardware support enhancements, and UI polish.

---

## 🚀 Getting Started

1. **Prerequisites**:
   - JDK 17 (Eclipse Temurin or OpenJDK)
   - Android SDK 35 (Platform 35, Build-Tools 35.0.0)
   - Android Studio Ladybug / Koala or any IDE with Kotlin & Gradle support

2. **Building & Testing**:
   ```bash
   # Run all unit tests
   ./gradlew test

   # Build debug APK
   ./gradlew assembleDebug

   # Install directly to a connected test device
   adb install -r app/build/outputs/apk/debug/app-debug.apk
   ```

---

## 📋 Guidelines

- **Zero-Telemetry Rule**: Ciger is strictly 100% offline and privacy-respecting. Never introduce network libraries, tracking SDKs, or `android.permission.INTERNET`.
- **Register Decoding Integrity**: When adding JEDEC EXT_CSD or UFS descriptor parsers, ensure unit tests covering raw hex inputs and fallback handling are added to `app/src/test/kotlin/com/ciger/EmmcDecodeTest.kt`.
- **Colon-Aligned Export**: Any new hardware section added must respect single-pass column alignment handled by `ReportFormat.formatReport()`.
- **Coding Style**: Idiomatic Kotlin, Jetpack Compose Material 3 standards, and descriptive variable naming.

---

## 🐛 Submitting Issues & PRs

- Use the provided [Bug Report](.github/ISSUE_TEMPLATE/bug_report.md) or [Feature Request](.github/ISSUE_TEMPLATE/feature_request.md) templates.
- When reporting a bug on a specific device, attach the output generated by the in-app **"Copy Colon-Aligned Diagnostic Report"** button.
